Read [the session contract](../common.md).

Identify the workload, compute shape, runtime or usage. Ask one focused
question for a required missing input. Call estimate_cost, using low and high
cases when an input is uncertain. For a compute decision, use decide first.

Done: the native calculator card where supported, a monthly range, its unit
rates and dates, assumptions, gaps and pricing links. Treat unpriced components
as gaps, not zero-cost items. Quotes, discounts, taxes and actual billing need
the user's billing data and current official pricing.
