Read [the session contract](../common.md).

1. If an exam is named, call start_here with goal certification and its exam id.
   For a general certification request, ask which exam; exam_prep lists them.
   A request explicitly asking to start immediately may use the default Data
   Engineer Associate, clearly saying that choice.
2. Begin the returned practice now. Use its interactive card where supported;
   in text, ask one question at a time and wait.
3. Score actual answers using quiz_me with exam, domain and answers. Teach the
   missed concepts from their source sections. Offer flashcards for that domain.
4. Use exam_prep for the full domain map and a plan weighted by the learner's
   misses and the published exam weights. Show thin or missing guide coverage
   and the official exam guide's link and verification date.

Done: practice has begun, or the one missing exam choice has been asked.
Practice scores indicate learning progress, not a certification-pass guarantee.
This is independent preparation, not Databricks-affiliated or real exam content.
